## 摘要

RFC-002 规范化 OpenCode Android 在 IME-less 眼镜设备上的零输入启动流程。通过 Intent extras 注入服务器凭证和语音配置，绕过 Settings UI，直接进入可用状态。本 RFC 定义 Intent schema、持久化策略、错误处理、窄屏 UX 和测试策略。

---

## 1. 问题陈述

**背景**：Rokid Glasses 等 IME-less 设备无法通过 Settings UI 输入服务器地址、用户名、密码、AI Builder token。当前 `feat/glasses-bootstrap` 分支通过 Intent extras 注入这些凭证，但存在以下设计缺口：

1. **Intent extras schema 未规范化**：使用裸 `EXTRA_TEST_*` 常量，无命名空间，易与其他应用冲突
2. **持久化策略不明确**：凭证是存磁盘还是仅会话级别？加密方式？
3. **错误处理缺失**：IME-less 设备无 logcat UI，失败时如何反馈？
4. **窄屏 UX 未设计**：启动后用户看到什么？如何确认配置成功？
5. **单元测试缺失**：`configureServer()` 和 `configureAiBuilder()` 无测试覆盖

---

## 2. 解决方案

### 2.1 Intent Extras Schema（规范化）

**命名空间**：`ai.opencode.client.bootstrap`

**定义的 extras**：

```kotlin
object BootstrapIntentExtras {
    private const val PREFIX = "ai.opencode.client.bootstrap"
    
    // Server configuration
    const val EXTRA_SERVER_URL = "$PREFIX.server_url"           // String, required
    const val EXTRA_USERNAME = "$PREFIX.username"               // String, required
    const val EXTRA_PASSWORD = "$PREFIX.password"               // String, required
    const val EXTRA_PROFILE_NAME = "$PREFIX.profile_name"       // String, optional (default: "Glasses")
    
    // AI Builder speech configuration
    const val EXTRA_AI_BUILDER_BASE_URL = "$PREFIX.ai_builder_base_url"  // String, optional
    const val EXTRA_AI_BUILDER_TOKEN = "$PREFIX.ai_builder_token"        // String, optional
    
    // Debug gate
    const val EXTRA_BOOTSTRAP_DEBUG_MODE = "$PREFIX.debug_mode"  // Boolean, default: false
}
```

**DEBUG-only gating**：

```kotlin
// MainActivity.onCreate()
val debugMode = intent.getBooleanExtra(
    BootstrapIntentExtras.EXTRA_BOOTSTRAP_DEBUG_MODE, 
    false
)

if (debugMode && BuildConfig.DEBUG) {
    // Process bootstrap extras
    val serverUrl = intent.getStringExtra(BootstrapIntentExtras.EXTRA_SERVER_URL)
    val username = intent.getStringExtra(BootstrapIntentExtras.EXTRA_USERNAME)
    val password = intent.getStringExtra(BootstrapIntentExtras.EXTRA_PASSWORD)
    // ... proceed with bootstrap
} else if (debugMode && !BuildConfig.DEBUG) {
    // Silently ignore bootstrap extras in release builds
    Log.w(TAG, "Bootstrap extras ignored: not a debug build")
}
```

**脚本调用示例**（`scripts/glasses_bootstrap.sh`）：

```bash
adb shell am start \
  -n ai.opencode.client/.MainActivity \
  -e ai.opencode.client.bootstrap.debug_mode true \
  -e ai.opencode.client.bootstrap.server_url "http://192.168.1.100:4096" \
  -e ai.opencode.client.bootstrap.username "marvin" \
  -e ai.opencode.client.bootstrap.password "secret" \
  -e ai.opencode.client.bootstrap.profile_name "Glasses Direct" \
  -e ai.opencode.client.bootstrap.ai_builder_base_url "https://api.ai-builder.example.com" \
  -e ai.opencode.client.bootstrap.ai_builder_token "token_xyz"
```

### 2.2 持久化策略

**Profile 存储**：

1. **HostProfile 磁盘持久化**（SettingsManager）
   - 通过 `configureServer()` 创建或更新 HostProfile，存入 EncryptedSharedPreferences
   - Profile 包含：id、name、transport、serverUrl、basicAuth（username + passwordId）
   - 设置为当前活跃 profile（`current_host_profile_id`）
   - 生命周期：启动后持久存在，用户可在 Settings 中修改或删除

2. **Basic Auth 密码加密存储**
   - 密码本身存 EncryptedSharedPreferences，key 为 `password_<profileId>`
   - Profile 中只保存 `passwordId`（指向密码的引用）
   - 导出 profile JSON 时不包含密码

3. **AI Builder Token 加密存储**
   - Token 存 EncryptedSharedPreferences，key 为 `ai_builder_token_<profileId>`
   - 与 profile 绑定，切换 profile 时自动切换 token
   - 导出时不包含 token

**实现代码**：

```kotlin
// MainViewModel.kt
suspend fun configureServer(
    serverUrl: String,
    username: String,
    password: String,
    profileName: String = "Glasses"
) {
    val profileId = UUID.randomUUID().toString()
    val passwordId = "pwd_$profileId"
    
    // 1. 保存密码到加密存储
    settingsManager.setPassword(passwordId, password)
    
    // 2. 创建 HostProfile
    val profile = HostProfile(
        id = profileId,
        name = profileName,
        transport = HostTransport.DIRECT,
        serverUrl = serverUrl,
        basicAuth = BasicAuthConfig(
            username = username,
            passwordId = passwordId
        )
    )
    
    // 3. 保存 profile 到磁盘
    settingsManager.saveHostProfile(profile)
    settingsManager.setCurrentHostProfileId(profileId)
    
    // 4. 配置 repository（REST API、SSE 等）
    repository.configure(profile)
    
    _state.update { it.copy(isConnected = true) }
}

suspend fun configureAiBuilder(
    baseUrl: String,
    token: String,
    profileId: String
) {
    // 1. 保存 token 到加密存储
    settingsManager.setAiBuilderToken("ai_builder_token_$profileId", token)
    
    // 2. 配置 AI Builder 客户端
    audioRecorderManager.configureAiBuilder(baseUrl, token)
    
    _state.update { it.copy(aiBuilderConnectionOK = true) }
}
```

### 2.3 错误处理

**IME-less 设备约束**：无 logcat UI、无系统输入法、无 Toast 显示（或显示不可靠）

**错误处理策略**：

1. **网络连接失败**
   - 尝试 3 次 health check（`GET /global/health`），间隔 2s
   - 失败后进入 "Disconnected" 状态，显示错误屏幕
   - 错误屏幕提供"重试"按钮（手动触发 health check）

2. **凭证错误**（401 Unauthorized）
   - 捕获 401 响应，标记为 "Authentication Failed"
   - 显示错误屏幕，提示用户检查用户名/密码
   - 提供"返回 Settings"按钮（允许手动修改）

3. **AI Builder 连接失败**
   - 语音功能降级为不可用
   - 显示警告但不阻止 Chat 功能
   - 用户可在 Settings 中重新配置或跳过

4. **持久化失败**（EncryptedSharedPreferences 写入异常）
   - 捕获异常，记录到 Crashlytics
   - 显示"配置保存失败"错误
   - 提供"重试"或"返回"选项

**错误屏幕 UI**（窄屏适配）：


### 2.4 窄屏 UX 设计（启动后确认屏幕）

**启动流程**：

1. **Intent 注入** → `MainActivity.onCreate()` 解析 extras
2. **配置应用** → `configureServer()` + `configureAiBuilder()`
3. **Health check** → 验证连接可用
4. **确认屏幕** → 显示配置成功，进入 Chat

**确认屏幕设计**：

```kotlin
@Composable
fun BootstrapSuccessScreen(
    profileName: String,
    serverUrl: String,
    onContinue: () -> Unit
) {

        verticalArrangement = Arrangement.Center,
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        Icon(
            Icons.Default.CheckCircle,
            contentDescription = null,
            modifier = Modifier.size(64.dp),
            tint = MaterialTheme.colorScheme.primary
        )
        Spacer(modifier = Modifier.height(24.dp))
        Text(
            text = "Connected",
            style = MaterialTheme.typography.headlineMedium,
            textAlign = TextAlign.Center
        )
        Spacer(modifier = Modifier.height(16.dp))
        Surface(
            modifier = Modifier
                .fillMaxWidth()
                .padding(horizontal = 8.dp),
            shape = RoundedCornerShape(8.dp),
            color = MaterialTheme.colorScheme.surfaceVariant
        ) {
            Column(modifier = Modifier.padding(12.dp)) {
                Text(
                    text = "Profile: $profileName",
                    style = MaterialTheme.typography.labelSmall,
                    color = MaterialTheme.colorScheme.onSurfaceVariant
                )
                Spacer(modifier = Modifier.height(4.dp))
                Text(
                    text = serverUrl,
                    style = MaterialTheme.typography.bodySmall,
                    color = MaterialTheme.colorScheme.onSurfaceVariant,
                    maxLines = 2,
                    overflow = TextOverflow.Ellipsis
                )
            }
        }
        Spacer(modifier = Modifier.height(32.dp))
        Button(
            onClick = onContinue,
            modifier = Modifier.fillMaxWidth()
        ) {
            Text("Continue to Chat")
        }
    }
}
```

**窄屏适配**：
- 单列布局，所有元素垂直堆叠
- 按钮宽度 100%，高度 48.dp（易于触摸）
- 文本使用 `maxLines` 和 `overflow = TextOverflow.Ellipsis` 防止超出屏幕
- 间距使用 Material 3 标准（8.dp、16.dp、24.dp）

## 3. 实现决策

| 决策 | 理由 |
|------|------|
| **Intent extras 命名空间** | 避免与其他应用冲突；便于版本化（未来可扩展为 `v2`） |
| **DEBUG-only gating** | 防止生产版本意外接受 bootstrap extras；提高安全性 |
| **磁盘持久化** | 用户可能需要多次启动；Settings 中可修改配置 |
| **密码加密存储** | EncryptedSharedPreferences 是 Android 官方推荐；与现有 BasicAuth 存储对齐 |
| **3 次 health check 重试** | 网络波动常见；3 次足以覆盖临时故障；避免过长启动延迟 |
| **确认屏幕** | IME-less 设备无法通过 Toast 反馈；显式屏幕确保用户知道启动成功 |
| **单元 + 集成测试** | 单元测试验证逻辑；集成测试验证 Intent 处理和 UI 流程 |

## 4. 范围外（Future）

- **NFC/QR 启动**：defer to RFC-003（需要 tag 写入工具、QR 生成、安全考量）
- **多设备启动配置**：defer to Phase 9（需要设备管理 UI）
- **启动配置导出**：defer to Phase 9（需要 JSON export 与 iOS 对齐）
- **后台启动验证**：defer to Phase 9（需要 Foreground Service）
